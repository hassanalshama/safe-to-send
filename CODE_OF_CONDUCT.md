# Code of conduct

Contributors must keep discussion technical, specific, and respectful.

Harassment, threats, discriminatory language, doxxing, deliberate disclosure of private document contents, and publication of real credentials are not accepted. Critique code and evidence directly; do not attack the person who submitted them.

Maintainers may edit or remove content, close discussions, or restrict participation when necessary to protect contributors, users, or confidential information.

Report conduct concerns privately through the repository owner's GitHub profile. Security disclosures belong in private vulnerability reporting, not in public issues.
