# Example files

These files are generated by `scripts/generate-fixtures.mjs`. They contain synthetic data only.

- `clean-sample.pdf` — baseline PDF expected to produce no findings.
- `unsafe-sample.pdf` — contains text beneath an opaque rectangle, invisible credential-like text, an annotation, identifying metadata, and incremental-save markers.
- `clean-sample.pptx` — baseline PowerPoint package expected to produce no findings.
- `unsafe-sample.pptx` — contains speaker notes, a hidden slide, hidden and off-slide objects, comments, custom data, an embedded file, external paths, and image metadata.

Expected release behavior:

```bash
node cli/safe-to-send.mjs examples/clean-sample.pdf --no-color
node cli/safe-to-send.mjs examples/unsafe-sample.pdf --no-color
node cli/safe-to-send.mjs examples/clean-sample.pptx --no-color
node cli/safe-to-send.mjs examples/unsafe-sample.pptx --no-color
```

Unsafe fixtures intentionally exit with code `2` at the default threshold.
