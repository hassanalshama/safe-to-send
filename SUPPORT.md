# Support

Use GitHub Issues for reproducible defects, false positives, missed synthetic cases, and focused feature requests.

Do not upload confidential files. Reduce the case to a generated or synthetic fixture first. Security vulnerabilities and cases involving real sensitive data must use private vulnerability reporting.

Questions that are specific to Microsoft Office, Adobe Acrobat, legal disclosure duties, or a company's document-retention policy should be directed to the relevant vendor or qualified internal adviser. Safe to Send reports file evidence; it does not provide legal certification.
